# tracker-swm_sud_rdo
Readiness Tracker SWM-SUD adalah alat pemantauan kesiapan kelembagaan dan operator pengelola sampah di 14 unit pemda Program SWM-SUD, yang merangkum skor kesiapan, gerbang serah terima aset, persyaratan PPK-BLUD, kepatuhan regulasi, anggaran, risiko, dan 176 aksi peta jalan dalam Excel dan dashboard web.
